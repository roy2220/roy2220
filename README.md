## My handcrafted projects

### Tools

[<img src="./icons/terminal.svg" height="14"> httpreplay](https://github.com/roy2220/httpreplay)
CLI tool for batch replaying HTTP requests with adjustable concurrency and QPS. Supports progress tracking, interruption (Ctrl-C), and resuming with updated settings. Perfect for restoring lost production HTTP request data.

### Libraries & Packages

[<img src="./icons/go.svg" height="14"> gad](https://github.com/roy2220/gad)
Tiny, unconventional dependency wiring framework for Go application startup.

[<img src="./icons/go.svg" height="14"> clbtransport](https://github.com/roy2220/clbtransport)
Minimalist Go http.Transport wrapper that implements client-side load balancing.

[<img src="./icons/go.svg" height="14"> filerotate](https://github.com/roy2220/filerotate)
Lightweight file writer for Go featuring time-based and size-based rotation with optional buffering.

[<img src="./icons/go.svg" height="14"> shcmd](https://github.com/roy2220/shcmd)
Go package for parsing shell-style text into commands.

[<img src="./icons/go.svg" height="14"> writev](https://github.com/roy2220/writev)
Go package for writing multiple buffers to a file or connection efficiently.

[<img src="./icons/go.svg" height="14"> stracetest](https://github.com/roy2220/stracetest)
Go test helper that runs subtests under strace to inject syscall faults.
